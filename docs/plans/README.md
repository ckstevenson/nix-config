# Plans and Proposals

This folder holds high-level plans, design proposals, and roadmap items related to the nix-config repository and its agents.

Purpose

- Collect RFC-style proposals and migration plans
- Track multi-step work that impacts architecture or several hosts
- Provide context for contributors and agents working on larger tasks

How to use

- Create one file per plan, for example: `plans/migrate-to-nix-unstable.md`
- Keep each plan focused: goals, assumptions, migration steps, and rollback strategy
- Link plans from PRs and issues for traceability

Placeholder files may be added here as work is planned. Treat this directory as living documentation for medium-term decisions.
